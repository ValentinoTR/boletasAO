Conecta el panel con GitHub

Solo se hace una vez en cada celular o computadora. Así el panel puede guardar los cambios directo en tu web.

  1. Abre GitHub para crear una llave de acceso (inicia sesión con tu cuenta si te lo pide).
    Crear llave en GitHub
  2. El enlace ya llena casi todo. Solo revisa que quede así:
    • Token name: Panel AO NEXUS
    • Resource owner: AONEXUSpe (la organización, no tu usuario)
    • Expiration: 365 days
    • Repository access: elige Only select repositories y marca AONEXUSpe.github.io ← esto lo tienes que elegir tú
    • Permissions: Contents en Read and write
    Luego toca el botón verde Generate token y copia la llave (empieza con github_pat_).
  3. Pega la llave aquí:

    La llave se guarda solo en este dispositivo. No la compartas con nadie.

Si GitHub dice que la llave está pendiente de aprobación, apruébala como dueño de la organización en Settings → Personal access tokens → Pending requests.

¿Prefieres no conectar? : haces tus cambios y el panel te descarga el archivo productos.json para que lo subas tú a GitHub.
